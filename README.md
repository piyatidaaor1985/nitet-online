# ห้องนิเทศก์ออนไลน์ ศน.ปิยะธิดา ช่างประเสริฐ

หน้าเว็บของห้องนิเทศก์ออนไลน์ สพป.สุรินทร์ เขต 1 เปิดผ่าน GitHub Pages ข้อมูลทั้งหมดเก็บใน Google Sheets ผ่าน Google Apps Script

## ไฟล์

- `index.html` หน้าเว็บทั้งหมด (ไฟล์เดียว)

## ตั้งค่า

ใน `index.html` ช่วงบนของไฟล์ มีบรรทัด

```js
window.API_URL = 'https://script.google.com/.../exec';
```

ใส่ลิงก์ Web app ของ Apps Script (ลงท้ายด้วย `/exec`) การเผยแพร่ต้องตั้งเป็น
- ดำเนินการในฐานะ: **ฉัน**
- ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**

## อัปเดตหน้าเว็บ

กด `index.html` > ไอคอนดินสอ หรือ Add file > Upload files แล้ววางไฟล์ใหม่ทับ กด Commit changes หน้าเว็บเปลี่ยนภายใน 1–2 นาที

ถ้ามีการแก้ `Code.gs` ต้องวางใน Apps Script แล้วสร้างเวอร์ชันใหม่ของการเผยแพร่เดิมด้วย
